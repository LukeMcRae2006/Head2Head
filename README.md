Head 2 Head is a 2D,  Platformer, Multiplayer game were you and a friend go Head 2 Head against one another to see who comes out on top! Imagine it kind of like a coin toss, except there are two heads! 

Controls: WASD -move, Space -Jump, Left Mouse Button -Fire.
